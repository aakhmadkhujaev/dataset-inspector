# Dataset Inspector

A Python-based Exploratory Data Analysis (EDA) tool for inspecting CSV datasets.

## Features

* Dataset shape analysis
* Numeric and categorical column counts
* Data preview
* Missing value detection
* Duplicate row detection
* Unique value analysis
* Statistical summary
* Outlier detection using the IQR method

## Technologies Used

* Python
* Pandas

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd dataset_inspector
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the program:

```bash
python main.py
```

Enter the path to your CSV dataset when prompted.

Example:

```text
Enter the path to the dataset (CSV file): tips.csv
```

## Example Reports

The tool generates:

* Dataset overview
* Missing values report
* Duplicate rows report
* Unique values report
* Statistics report
* Outlier report
